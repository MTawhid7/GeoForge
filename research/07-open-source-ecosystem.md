## 7.2 License analysis for GeoForge integration

| Tier | Licenses | Systems | Policy |
|---|---|---|---|
| **Safe to link/embed** | Apache-2.0, MIT, BSD | AG1, AG2 DDAR, mathlib, LeanEuclid, Penrose, SymPy, nanoproof, InterGPS | Free to integrate, modify, ship |
| **Weak copyleft** | LGPL-3.0 | GeoCoq | Fine as unmodified dependency (unlikely to be used anyway) |
| **Strong copyleft** | GPL-3.0 | TongGeometry, FormalGeo, GeoGebra Discovery | Do **not** link into the pipeline codebase. Options: (a) ideas-only reimplementation, (b) isolated subprocess with serialized I/O if ever needed, (c) accept GPL for the whole offline pipeline (viable since the pipeline isn't distributed — but keep clean boundaries anyway) |
| **Unresolved** | none declared | ~~**Newclid**~~ *(resolved — see note below)*, Goedel-Prover-V2 | ~~Blocker for Newclid adoption.~~ Fallback primary: AG2 DDAR (Apache-2.0) |

> **Update 2026-08-01 (post-clone):** the Newclid monorepo declares licenses per subpackage rather than
> at the repo root (which is why the GitHub API and PyPI show none): `newclid/LICENSE`, `yuclid/LICENSE`,
> and `ncdgen/LICENSE` are all **Apache-2.0** (ncdgen with a Harmonic NOTICE). The adoption blocker is
> cleared. Bonus finding: **`ncdgen`** is a synthetic JGEX problem-generation library built on Newclid —
> a maintained scaffold for our generator loop (see docs/03 §3.2).

Note on generated *data*: puzzles generated by running a GPL tool are generally not GPL-derived works, but
the pipeline code that imports GPL modules is. Keep the distinction sharp.

## 7.3 Ecosystem health assessment

- **Momentum:** the AG-lineage (AG2 release, Newclid 3.0, Seed, Tong) all shipped within the last 18
  months; formal-geometry (LeanGeo) and evaluation (FGeo-Eval) layers are appearing. This is a growing
  ecosystem, not an abandoned research niche.
- **Fragility:** the load-bearing candidate (Newclid) is a small-team project, 95★, undeclared license.
  Mitigations: vendor a pinned fork; keep the solver behind an adapter interface (see
  [09-architecture-recommendation.md](09-architecture-recommendation.md)) so AG2-DDAR or a future
  Seed-Geometry release can replace it; contribute fixes upstream to build relationship.
- **Format convergence:** JGEX-style problem text is the de-facto interchange format (AG1, AG2, Newclid all
  read variants of it). Adopting it as GeoForge's construction DSL surface buys benchmark
  interoperability for free.
